# COVID-19 India Power BI Analytics

Interactive Power BI dashboard analyzing COVID-19 trends across India.

## 🛠️ Tools
- Power BI
- DAX
- Power Query
- Data Modeling

## 📊 Analysis
- Confirmed Cases
- Deaths & Recoveries
- Daily Case Trends
- State-wise Analysis
- Testing & Vaccination

## 🔍 Key Insights
- 34M+ reported COVID-19 cases analyzed
- 414K+ peak daily cases
- State-wise comparison of COVID-19 impact
